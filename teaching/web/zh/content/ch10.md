**开场问题：读懂和做出来之间，隔着的是什么？**不是更多知识——12 周的知识已经够用——而是一个**可证伪的小问题**：它小到两周能做完，又大到做完后你能拿出一个别人可以复核的结论。CSAPP 的实验设计哲学是：宁可回答一个小问题答得干净利落，也不要在一个大问题上留下一堆“可能、大概”。本章三个方向（复现验证 / 功能扩展 / 教学再包装）都按这个标准组织，每个方向都配了最小可行里程碑。

## 10.1 方向 A：复现并批判性验证（最稳）

“批判性验证”的第一课是**对账**：把你要验证的结论与权威结果表（docs/RESULTS.md）逐字段核对——语料是什么、协议是按源图分组还是随机切分、数字有没有置信区间。摘一行主表做示范（BOSSbase、按源图 holdout）：

| **模型** | **特征** | **AUC** | **95% CI** |
| --- | --- | --- | --- |
| LGB-11d | 11 维 | 0.7128 | [0.6913, 0.7360] |
| LGB-143d | 143 维 | 0.8062 | [0.7894, 0.8225] |
| LGB-53d | 53 维 | 0.7172 | [0.6943, 0.7406] |
| xuNet（裸像素 CNN） | 原始像素 | 0.5007 | [0.5004, 0.5012] |
| yenet（SRM+CNN） | 30 SRM 固定核 | 0.9541 | [0.9463, 0.9630] |

拿到这张表，好的批判性问题会自己冒出来：143d 对 11d 的提升（+0.09）主要来自 SRM 特征还是数据规模？（8.8 节的 A/B 实验已回答一半——同数据下 143 维另有增益。）为什么裸 CNN 的置信区间那么窄却贴着 0.5？（它稳定地“不会”，稳定也是一种可复现。）把你冒出的问题写下来，挑一个能动手的。

选 README / docs/RESULTS.md 中的 1～2 个结论，自己重新跑并尝试“推翻”它：

复现码族图：理论 α(p) 是否与实测吻合？p 取大后偏差从哪来？

复现检测实验：换你自己的照片训练，比较 v1 11 维基线（约 0.75–0.79）与 README 的 v1.4 双版本结果，观察照片风格对 AUC 的影响；

复现篡改实验：改 1 像素、改 1 行、改 1 块，解码失败率各是多少？

| **验收项** | **通过标准** |
| --- | --- |
| 实验日志 | 记录环境、命令、参数、原始输出 |
| 图表 | 至少 2 张自绘曲线/对比图，坐标与图例完整 |
| 结论 | 能区分“验证了论文”与“与论文不一致”并给原因 |
| 可复现 | 提供一键脚本或逐条命令，别人能重跑 |

## 10.2 方向 B：功能扩展（最有成就感）

支持中文/UTF-8 消息：v1.8 起已在 encode_string() 内实现（长度头单位是字节数），可对照源码校对你的实现；

彩色通道扩展：目前仅用 R 通道，可研究 R/G/B 三通道如何分配容量与安全性；

新增特征：在 v1 11 维或 v2 143 维基础上加一个你认为能区分 clean/stego 的统计量，用 GroupKFold 评估 AUC 是否真的上升；

对比新算法：实现朴素 LSB 替换，与 nsF5 在相同载荷下比较 Gn 塌缩与检出率。

> **避坑提醒｜
每次扩展都要跑 test_core.py 与 test_steg.py，保证“嵌入→解码”往返仍然成立。修改编码方案时，解码端必须同步修改——这是初学者最常忘的。**

## 10.5 汇报/答辩常见问题与应答要点

答辩的加分项往往不在答案本身，而在**引用的口径**。同样一句“AUC 0.81”，说出“LGB-143d，BOSSbase 1.01，按源图 holdout，95% 置信区间 [0.79, 0.82]，另有 1514 张真实干净照片的 OOD 误报率实测”与只说一个数字，是两个档次。评委由此判断你有没有亲手跑过实验——因为只有跑过的人才会自然地带出这些限定词。

| **高频问题** | **应答要点** |
| --- | --- |
| LSB 隐写为什么能被发现？ | 相邻灰度对被拉平（卡方）+ LSB 结构塌缩（RS），先讲直觉再讲统计量 |
| 矩阵编码为什么“改得少”？ | n=2ᵖ−1 个位置承载 p 位，H 列互异 → 任一伴随式差对应唯一位置 |
| nsF5 相比 F5 好在哪里？ | 湿纸预标记湿点、只在干点解方程，无收缩无重嵌 |
| 湿纸编码怎么解方程？ | GF(2) 线性方程 H_dry·y=d，先试单列/双列，再高斯消元兜底 |
| 为什么不用裸 CNN？ | 小样本弱信号下学不到泛化特征；特征+简单模型更稳（AUC 实证） |
| AUC 0.756 说明什么？ | 排序能力尚可但弱密度难检；AUC 与“具体阈值下检出率”是两回事 |
| 哈希键控能防什么？ | 防位置可预测/复制；能感知普通篡改，但不是密钥化 MAC |
| C++/GPU 加速有没有风险？ | 有：必须做跨语言一致性校验，否则嵌入解码会不可逆 |
